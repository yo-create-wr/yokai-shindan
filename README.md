# 妖怪診断 第一段階版

GitHub Pagesでそのまま公開できる静的サイトです。

## 実装内容

- 12問の妖怪タイプ診断
- 12妖怪・2パターンのWebP画像
- 質問中の妖怪アニメーション
- 診断結果の端末内保存（localStorage）
- 日付ごとに固定される「今日の行動アドバイス」
- 3テーマ別の行動提案
- 日替わりの妖怪状態・画像・動き
- 7日間の訪問記録
- 7回訪問後の振り返りメッセージ
- 別日に訪れると増える妖怪図鑑
- 結果共有・共有画像生成
- 外部ライブラリ、サーバー、会員登録なし

## サイトの位置づけ

質問への回答から考え方や行動の傾向を分類し、妖怪の特徴になぞらえて紹介するエンターテインメント型の性格診断です。未来予測や専門的な心理判定は行いません。

## 公開方法

このフォルダの内容をGitHubリポジトリのルートへ配置し、`Settings → Pages`から`main / root`を公開元に設定してください。

## 画像フォルダ

画像は次の二階層に配置してください。

```text
assets/
└─ yokai/
   ├─ pattern-a/
   └─ pattern-b/
```

## 保存について

診断結果、訪問日、妖怪図鑑、今日のテーマ選択はブラウザの`localStorage`に保存されます。別端末への同期やブラウザデータ削除後の復元には対応していません。

## 主な構成

- `index.html`
- `og-image.svg`
- `assets/yokai/pattern-a/*.webp`
- `assets/yokai/pattern-b/*.webp`


## Language switching

- 日本語 / English 切替ボタン対応
- 言語設定は `localStorage` の `yoCreateLanguage` に保存
- ポータルと同じオリジン上で言語設定を共有
- 再訪時は最後に選択した言語で表示
